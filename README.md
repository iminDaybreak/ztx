# Guide: Create a private repository with a README
## Prerequisites
1. You have logged into your GitHub account on a desktop browser (English interface).
2. Stable internet connection.

## Steps
1. Click the plus `+` icon at the top-right of any GitHub page, then choose **New repository**.
2. Enter a repository name (no spaces). Select the **Private** visibility option.
3. Tick the checkbox: **Add a README file**.
4. Click the green **Create repository** button.
5. Wait for the repository page to load.

## Result Check
✅ Check: The repository page opens, and you can see the README.md file displayed on the main page.
